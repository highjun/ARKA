# 정비 전 ADR 스냅샷 (2026-09-09)

ADR 재검토(계획의 r0)를 시작하기 직전의 `docs/adr/` 20개와 `docs/ADR_CANDIDATE.md`·`docs/lint-plan.md`를 그대로 뜬 것이다. 재작성 중 원문과 대조하려고 둔다.

**정본이 아니다.** 결정의 정본은 언제나 `docs/adr/`이다(→ [CONVENTIONS.md](../../../CONVENTIONS.md)의 `## ADR`). 여기 있는 것은 읽기 전용 화석이고, 고치지 않는다.

`docs/copy/adrs/`는 같은 내용의 백업이다.

**r0가 끝나면 두 디렉터리를 지운다** — 같은 내용이 세 곳에 있으면 어느 것이 정본인지 묻게 되고, 그게 이 정비가 없애려는 바로 그 문제다. git 이력이 이미 영구 보관하므로 그때는 `git show`로 충분하다.
