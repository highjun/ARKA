# ADR 0002: 주석과 문서는 한글로 쓴다

## 결정: 
- 이 저장소의 리뷰어를 위해서 한글로 주석과 문서를 쓴다. 
- 주석·TSDoc·마크다운 문서·테스트 이름(`describe`/`it`)은 한글로 쓰고, 코드 식별자와 런타임 문자열(`throw new Error(...)` 메시지 등) 등 영문이 자연스러운 부분만 영문으로 쓴다. 
- 테스트 이름은 문자열 리터럴이지만 사람이 읽는 설명문이므로 한글로 쓴다. 실패 출력이 곧 리뷰 대상이다.

## 기각:
- 전부 영문 — 리뷰어가 읽는 속도가 떨어져 계약 우선 리뷰가 성립하지 않는다. 식별자까지 한글 — 라이브러리 타입과 섞였을 때 오히려 읽기 나쁘고 생태계 관례에서 벗어난다. 영문으로 쓰고 나중에 번역 — 두 벌이 생기고 한쪽이 반드시 낡는다.

## 상태: 
승인됨.
