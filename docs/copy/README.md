# 정비 전 문서 — 아직 재작성되지 않은 것들

ADR 재검토(r0)를 시작하기 직전의 문서를 뜬 것이다. **여기 남아 있는 것이 곧 아직 새
`docs/adr/`로 옮겨지지 않은 것**이다 — 따로 목록을 두지 않는다. 옮겨지면 그 파일을 지운다.

**정본이 아니다.** 결정의 정본은 언제나 `docs/adr/`이다(→ [CONVENTIONS.md](../CONVENTIONS.md)의
`## ADR`). 여기 있는 것은 읽기 전용이고, 고치지 않는다.

혹시 모를 백업은 `docs/legacy/adrs/`에 손대지 않은 채로 있다. 옛→새 번호 대응표도 거기 있다.

## 절반만 옮겨진 것 — `0013-build-and-config.md`

이 하나는 파일이 남아 있는 이유가 다르다. **일부는 이미 새 ADR에 있고 일부는 갈 곳이 없다.**

| 옛 0013의 항목 | 어디로 |
|---|---|
| 설정은 그것이 다스리는 패키지에 둔다 | [ADR 0003](../adr/0003-live-next-to-what-they-govern.md) |
| 루트에는 전 패키지 공통만 / 산출물은 한 폴더에 모으고 추적하지 않는다 | [ADR 0002](../adr/0002-repo-root.md) |
| **vitest 설정을 `vite.config.ts` 안에 둔다** (+ 별도 `vitest.config.ts` 기각) | 아직 없다 |
| **입력인 것은 커밋한다** — VRT 기준 이미지, E2E fixture | 아직 없다 |
| **산출물을 린트의 `ignores`에도 넣는다** (+ `.gitignore`에만 넣기 기각) | 아직 없다 |
| **커스텀 린트 규칙의 자리** (+ npm 패키지로 빼기 기각) | 아직 없다 |

남은 넷은 테스트·빌드 설정을 다루는 ADR이 재작성될 때 함께 간다.
