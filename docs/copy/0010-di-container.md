# ADR 0010: DI 컨테이너를 직접 만든다

## 결정:
- `Token<T>`가 타입을 들고 다닌다 — `createToken<IThemeModel>('themeModel')`. `resolve`의 반환 타입이 추론된다.
- 만드는 방법은 **팩토리 하나**로 통일하고 수명만 고른다 — `singleton`/`scoped`/`transient`/`value`. 의존은 팩토리 안에서 명시적으로 `c.resolve(...)` 한다.
- **계층 스코프**: 자식은 부모를 보고 형제는 못 본다. `dispose`는 아래로만 전파된다.
- **순환 의존을 감지해 명확한 에러로 던진다.** 없으면 스택 오버플로로 터져 원인 추적이 어렵다.

## 기각:
- **awilix** — 문자열 키라 오타가 런타임 에러가 되고, 마이크로커널로 가면 익스텐션끼리 키가 충돌한다. Proxy가 생성자 인자 **이름**을 보고 주입해서, 무엇이 주입되는지 코드를 읽어 알 수 없다.
- InversifyJS — 데코레이터와 `reflect-metadata`가 필요해 빌드 설정이 늘고, 번들에 런타임 메타데이터가 들어간다.
- React Context만 쓰기 — 화면 밖(커맨드 핸들러, 조립부)에서 의존을 꺼낼 수 없다.
- awilix와 같은 API로 만들어 이전 비용을 줄이기 — 문자열 키의 문제를 그대로 물려받는다. 클래스는 어차피 `constructor({ dep })` 모양이라 바뀌는 것은 조립부 한 곳뿐이다.

## 상태:
승인됨. ADE 문서 §5의 "토큰 기반(symbol)"을 구현한 것이다.
