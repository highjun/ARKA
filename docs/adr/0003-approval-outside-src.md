# ADR 0003: `packages/*/src/` 밖은 사용자 승인 없이 건드리지 않는다

## 맥락:
사용자의 의도가 전혀 고려되지 않고, 검토 없이 여러 설정 파일들이 저장소 루트, 패키지 루트 등에 쌓이면서, 영향을 여러 곳에 미친다.
이로 인해 side-effect가 계속 발생하고, 사용자가 Repo를 리뷰하기 어려워졌다.
그에 따라, 어떤 변경이 일어날 때, 그 변경이 일어나는 자리를 정할 수 있는 명확한 규칙이 필요하다.

## 결정:
- **`packages/*/src/` 밖을 바꾸는 것은 구조 변경이다.** 사용자가 명시적으로 지정하지 않으면 건드리지 않는다.
- 예외적으로 임시 폴더는 상관 없다.(`.claude/`,`.output/`)
- **승인은 PR 리뷰다.** 에이전트는 자기 계정(`sangjun-agent`)으로 브랜치를 밀고 PR을 연다. 사용자가 diff를 보고 승인해야 `main`에 합쳐진다. 누가 만들고 누가 승인했는지가 PR에 영구히 남는다.
- 2026-09-13 이전에는 `commit-msg` 훅이 커밋을 막고 `Reviewed-by-human` 트레일러로 지나갔다. 에이전트가 별도 계정을 얻고 저장소가 공개되어 브랜치 보호를 걸 수 있게 되면서 그 자리를 PR 승인이 대신한다.

## 기각:
- 자유롭게 두고 리뷰에서 거르기 — 이번 세션에 `git add -A`가 **의도하지 않은 것을 세 번 쓸어담았다**(추적된 산출물 5.8MB, 사용자의 문서 삭제, 개인 메모). 리뷰가 diff를 다 읽지 못한다.
- 세어 보여주기만 하기 — 경고는 스크롤에 묻힌다. 기본값이 "지나간다"인 한 세 번의 사고를 한 번도 막지 못했을 것이다.
- 사람만 지나갈 수 있게 만들기 — 에이전트와 사용자가 **같은 셸을 같은 권한으로** 돌린다. 훅·설정 파일 어느 층에서도 둘을 가를 수 없다(관리자 설정은 sudo가 필요하고 에이전트에겐 없지만, 그건 사용자도 못 쓴다). 억지 비대칭 대신 **안전한 기본값과 남는 기록**을 택했다.

## 대가:
- **거의 모든 라운드에 한 번의 행위가 더 든다.** 밖을 안 건드리는 라운드가 드물어서다.
- 이 규칙이 막는 것은 악의가 아니라 **부주의**다.

## 강제:
- **룰셋** `main` — PR 필수, 승인 1개, 새 push 시 이전 승인 무효, 강제 push·삭제 금지. 에이전트 계정은 우회할 수 없다.
- **CODEOWNERS** `.github/CODEOWNERS` — 배치·설정·결정이 사는 자리에 사용자가 리뷰어로 자동 지정된다.
- **파이프라인** `ops/pipeline/outsideSrc.ts` — `src/` 밖을 건드린 경로가 PR 본문에 **언급되는지** 본다. 리뷰어가 diff를 열기 전에 무엇이 밖이었나를 알아야 한다. 설명이 타당한가는 사람이 판정한다.

## 상태:
승인됨 (2026-09-10). 2026-09-13 개정 — 강제를 훅에서 PR 승인으로 옮겼다. 2026-09-14 개정 — 본문 언급 여부를 CI가 본다.
