# ADR 0003: `packages/*/src/` 밖은 사용자 승인 없이 건드리지 않는다

## 맥락:
설정 파일이 늘수록 관리가 어려워지는데, 늘리는 것은 한 줄이고 지우는 것은 라운드 하나다.
`packages/*/src/` 밖에 있는 것은 배치·설정·결정이라 파급이 전역이고, 그중 상당수가 "왜 여기 있나"에 답이 없는 채로 쌓였다.

## 결정:
- **`packages/*/src/` 밖을 바꾸는 것은 구조 변경이다.** 사용자가 명시적으로 지정하지 않으면 건드리지 않는다.
- 밖에는 설정 파일·루트 항목·`ops/`·문서·각 패키지의 `test/`·`package.json`이 있다.
- **늘리는 쪽이 특히 그렇다** — 새 설정 파일, 새 의존성, 새 스크립트는 넣기 전에 묻는다.
- 지금 배치가 기준선이다 → [ADR 0002](0002-live-next-to-what-they-govern.md)

## 기각:
- 자유롭게 두고 리뷰에서 거르기 — 이번 세션에 `git add -A`가 **의도하지 않은 것을 세 번 쓸어담았다**(추적된 산출물 5.8MB, 사용자의 문서 삭제, 개인 메모). 리뷰가 diff를 다 읽지 못한다.
- 기본 차단 — 실측으로 **커밋 54개 중 밖을 안 건드린 것이 0개**다. 전건 위반인 규칙은 규칙이 아니라 백로그다. 막는 것이 아니라 **드러내는 것**이어야 한다.

## 대가:
밖을 고쳐야 하는 라운드마다 확인이 한 번 더 든다. 위 실측대로 그건 거의 모든 라운드다.

## 강제:
- **리뷰** — 지금은 이것뿐이다. 린트로는 할 수 없다: ESLint는 파일의 *내용*을 보지 *무엇이 바뀌었는지*를 모른다
