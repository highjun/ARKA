# ADR 0003: 문자열 경로 대신 URI를 쓴다

## 결정:
- 에디터는 단순히 파일만 여는 것이 아니라 git의 이전 버전도 열어보게 되는데, 디스크 파일과 git의 이전 버전은 단순 경로만으로는 구분할 수 없다.
- 이를 해결하기 위해서, `scheme`과 `path`를 갖는 URI를 쓴다.
- URI는 값 클래스로 두고, `URI.parse()`/`URI.file()`로만 생성해 검증을 우회할 수 없게 한다.
- 단, query/fragment 형태의 URI는 두지 않는다.

## 기각:
- scheme 없는 경로(`/workspace/main.py`) — 현재 파일과 git 이전 버전이 같은 문자열이 되어 구분할 수 없다.
- 검증된 문자열 타입(branded string) — JSON 전송과 `Map` 키는 편하지만, `as Uri`로 검증을 우회할 수 있고, 앞으로 필요해질 경로 조작(`basename`·`dirname`·`join`)을 붙일 자리가 없다.
- query/fragment는 당장 필요하지 않기에 없는 형태로 관리한다.

## 상태:
승인됨.
