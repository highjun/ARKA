# ADR 0004: 주석은 코드에 없는 정보만 쓴다

## 결정: 
- 에이전트가 코드를 작성하면서, "무엇을 하는지" 설명하는 주석과 긴 배경 설명이 대량으로 붙는다.
- 주석에 쓰는 내용을 네 가지로 한정한다.
    - **계약** — 호출자가 알아야 하지만 시그니처에 드러나지 않는 것. 던지는 에러, 부수효과(구독·dispose 필요 여부), 제약 조건.
    - **왜** — 대안이 있었는데 이 방식을 고른 이유.
    - **비자명한 로직** — 코드는 읽히지만 왜 맞는지는 보이지 않는 것. 불변식, 까다로운 계산, 놀랄 만한 동작.
    - **외부 사정** — 라이브러리 버그 우회, 외부 시스템의 이상한 특성처럼 우리 판단이 아닌 이유.
- 계약은 TSDoc으로, 나머지 셋은 인라인 주석으로 쓴다.
- 다음은 쓰지 않는다.
    - 무엇을 하는지 — 코드가 이미 말한다.
    - 타입이 말하는 것 — 시그니처가 이미 말한다.
    - 긴 배경 설명 — ADR로 옮기고 주석에는 링크만 남긴다.

## 기각: 
- 주석 전면 금지 — 던지는 에러와 제약 조건은 시그니처만으로 전달되지 않는다.
- 자유 서술 허용 — `uri.ts`의 클래스 주석이 ADR 0003과 통째로 겹쳐, 두 곳이 따로 낡을 상태였다.

## 상태: 
승인됨.
