## 설명

`IShellViewModel.isNarrow`(`IViewport`, `matchMedia`)는 있지만 `Shell`·`Tab`은 `data-narrow` 속성만 찍는다.
계약이 말하는 표현 — 사이드바·아래 창이 겹쳐 뜨고, 탭 띠 대신 "지금 탭 하나 + 목록에서 고르기" — 은 아직
미디어쿼리(드로어)까지만 있다.

## 인수 조건

- [ ] `Tab`이 `isNarrow`에서 띠를 접고 목록 선택으로 바꾼다 — 스토리·테스트
- [ ] `Shell`이 `isNarrow`에서 아래 창을 겹쳐 띄운다
- [ ] 드로어 개폐를 미디어쿼리가 아니라 `data-narrow`로 가른다 — CSS의 `768px` 분기를 지운다
