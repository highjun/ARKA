## 설명

`PreToolUse` 훅(`ops/hooks/scopeGuard.ts`)을 2026-09-10에 달았다. **남은 것은 확인과 구멍 하나다.**

**확인**: `.claude/settings.json`을 세션 도중에 만들어 **이번 세션에서는 안 걸렸다**(밖의 파일을
Write로 만들어 봤는데 그냥 통과했다). 설정은 세션 시작 때 읽힌다. **다음 세션에서 실제로 묻는지
봐야 한다.**

**구멍 — 셸.** 훅은 `Write`·`Edit`만 가로챈다. `Bash`로 고치면 안 걸리는데, 셸 명령이 무엇을
쓰는지 미리 알 수 없어서다(`>`·`sed -i`·heredoc·python 스크립트…). 이번 세션의 파일 수정은
**거의 전부 Bash**였으므로 이 구멍이 곧 게이트의 크기다.

메울 길 둘:
- `CLAUDE.md`에 "밖의 파일은 Write·Edit로 고친다"를 적었다 — **규칙이지 강제가 아니다**
- `PostToolUse`로 Bash 뒤에 `git status`를 비교해 밖의 변경을 **드러낸다.** 막지는 못하지만
  셸 파싱에 기대지 않아 새지 않는다

**막지 않고 묻는 이유**: 실측으로 커밋 54개 중 밖을 안 건드린 것이 0개다. 막으면 모든 라운드가
선다. 물으면 사람이 그 자리에서 승인하고, **에이전트는 스스로 승인할 수 없다.**

## 인수 조건

- [ ] 다음 세션에서 밖의 파일을 Write하면 실제로 확인을 묻는다
- [ ] `packages/*/src/`·`.claude/`·`.output/`은 아무 말도 하지 않는다
- [ ] 셸로 고치는 경로가 드러나거나(PostToolUse), 규칙으로 남은 이유가 적혀 있다
