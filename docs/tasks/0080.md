## 설명

사람이 미리 보지 않는 PR이 생긴다(→ [ADR 0015](../adr/0015-review-tiers.md)). 대신 하루 한 번(ADR 0013의 매일 Trigger) 그날 자동 머지된 PR을 제목·태스크·CI 링크만으로 묶어 남긴다. 사람은 훑고 이상하면 revert PR을 연다. 남기는 자리(이슈·디스커션)는 이 태스크에서 정한다.

## 인수 조건

- [ ] 매일 한 번 돌고, 자동 머지된 PR이 없는 날은 아무것도 남기지 않는다
- [ ] 항목에 제목·태스크 번호·check 링크가 있다
