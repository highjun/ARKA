## 설명

`packages/client/tsconfig.json`이 `"types": ["vitest/globals"]`로 `node`를 일부러 뺐는데도
`src/`에서 `process.env`를 쓰면 **타입 검사를 통과한다**. `vitest/globals`가 `@types/node`를
전이 의존으로 끌고 오기 때문이다.

2026-09-10 실측 — `types: []`로 바꾸면 `process`가 안 보이고, `["vitest/globals"]`면 보인다.
그래서 원인이 이것 하나로 좁혀진다.

브라우저 패키지가 `process`·`Buffer`·`__dirname`을 보면 안 된다. `tsconfig`로는 막을 수단이
없다 — `types` 배열은 **전역 자동 포함**만 통제하고 전이 의존은 못 막는다.

이 저장소의 답은 린트다. `model/`·`viewmodel/`이 이미 `no-restricted-globals`로 `fetch`·
`window`·`document`를 막고 있으니 같은 방식으로 `src/**`에 Node 전역을 더한다.

## 인수 조건

- [ ] `src/` 아무 곳에서 `process.env`를 쓰면 `pnpm run lint`가 빨갛다
- [ ] `Buffer`·`__dirname`·`global`도 같이 잡힌다
- [ ] `test/`·`vite.config.ts`·`.storybook/`은 대상이 아니다 — 거기는 Node에서 돈다
- [ ] 켜기 전 위반이 0건임을 실측한다
