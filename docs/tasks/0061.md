## 설명

ADR 0011이 정한 대로 자작 규칙 자리를 기성 플러그인으로 채운다.
**마지막 라운드인 이유**는 켜는 조건이 "위반 0"이고, 위반을 없애는 것이 C2~C8이기 때문이다.

가져올 것 — `eslint-plugin-primer-react`(recommended), `eslint-plugin-jsx-a11y`(recommended),
`eslint-plugin-project-structure`(폴더 구성·파일 이름·스토리 존재), `eslint-plugin-boundaries`(슬라이스
경계·`model/`의 상태 라이브러리), `@eslint-react/eslint-plugin`(`no-forward-ref`),
`eslint-plugin-storybook`(recommended), `@primer/stylelint-config`.

코어 선택자로 쓸 것 — `view/`가 `useViewModel`만 부르기, `it()`/`test()` 이름이 한글이기,
Primer `IconButton` 직접 import 막기.

빠지는 것 — 우리 stylelint 색 규칙 셋(`color-no-hex`·`color-named`·`function-disallowed-list`)은
`@primer/stylelint-config`가 더 넓게 덮는다. 자작 규칙은 `arka/max-comment-lines` 하나만 남는다.

**하나씩 켠다.** 플러그인을 넣고 위반을 센 다음, 0이면 error로 켜고 아니면 같은 라운드에서 없앤다.
못 없애면 켜지 않고 남은 위반을 태스크로 넘긴다. 곁가지로 하네스를 빠뜨린 테스트 다섯을 채운다.

**플랜에서 바꾼 것 둘.**

- `eslint-plugin-boundaries` → `import-x/no-restricted-paths` zone. 캡처 변수(`{{from.slice}}`)로 "형제끼리만 금지"를 한 줄에 쓰려고 골랐는데 v7에서 우리 배치에 걸리지 않았다(요소 인식은 되는데 정책이 안 발동한다). zone에 슬라이스 다섯을 열거하면 정확히 같은 경계가 되고, 일부러 깨뜨려 잡히는 것을 확인했다.
- `eslint-plugin-project-structure` → `test/structure.test.ts`. `folder-structure`가 트리 **전체**를 선언하게 만드는데, 정하려는 것은 컴포넌트 폴더 하나의 모양뿐이다. "옆에 파일이 있나"는 구문이 아니라 파일 시스템 질문이라 테스트가 맞는 자리다 — 스토리·테스트·배럴 유무와 그룹 배럴 부재를 다섯 단정으로 본다.

**끈 stylelint 규칙 둘.** `primer/spacing`은 Primer 자신의 `--space-*` 토큰(primitives 11에 문서
주석까지 달려 있다)을 거부한다 — 규칙이 그 토큰 세트보다 낡았다. `csstools/value-no-unknown-custom-properties`는
토큰 정의가 패키지 CSS 안에 있어 172건을 전부 미지의 것으로 본다.

**드러난 결함들.** 켜자마자 23건이 잡혔고 대부분 실제 문제였다.

- `Message`의 `role` prop이 HTML `role`을 가리고 있었다 — 소비자가 ARIA 역할을 줄 수 없었다. `author`로 바꿨다
- 리사이즈 손잡이가 `button`인데 `aria-orientation`을 달고 있었다 — 그 역할은 받지 않는다. 포커스 받는 `separator`(창 분할의 정본 패턴)로 바꿨다
- `FileTree` 행의 클릭이 키보드 처리와 다른 원소에 있었다. `treeitem`으로 올리면서 중첩 행의 버블링을 "가장 가까운 treeitem만" 조건으로 막았다
- React 19의 `<Context>` 표기로 여덟 곳을 옮겼다
- `Tab` 헤더의 `nested-interactive`는 고치지 못했다 — TASK-66

**하네스 빠진 것 열을 채웠다.** `CrashScreen`·`NotificationList`는 닫힌 props를 열어야 했고,
`Message`·`ChatRoom`·`InputComposer`·`TextEditor`는 `ref`를 아예 받지 않고 있었다. `ErrorBoundary`는
자기 DOM을 안 그려 `shared/utils/errorBoundary.tsx`로 옮겼다(하네스 대상이 아니다).
