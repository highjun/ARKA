## 설명

[ADR 0011](../adr/0011-lint-off-the-shelf.md)이 정한 대로 자작 규칙 자리를 기성 플러그인으로 채운다.
**마지막 라운드인 이유**는 켜는 조건이 "위반 0"이고, 위반을 없애는 것이 C2~C8이기 때문이다.

가져올 것 — `eslint-plugin-primer-react`(recommended), `eslint-plugin-jsx-a11y`(recommended),
`eslint-plugin-project-structure`(폴더 구성·파일 이름·스토리 존재), `eslint-plugin-boundaries`(슬라이스
경계·`model/`의 상태 라이브러리), `@eslint-react/eslint-plugin`(`no-forward-ref`),
`eslint-plugin-storybook`(recommended), `@primer/stylelint-config`.

코어 선택자로 쓸 것 — `view/`가 `useViewModel`만 부르기, `it()`/`test()` 이름이 한글이기,
Primer `IconButton` 직접 import 막기.

빠지는 것 — 우리 stylelint 색 규칙 셋(`color-no-hex`·`color-named`·`function-disallowed-list`)은
`@primer/stylelint-config`가 더 넓게 덮는다. 자작 규칙은 `arka/max-comment-lines` 하나만 남는다.

**하나씩 켠다.** 플러그인을 넣고 위반을 센 다음, 0이면 error로 켜고 아니면 같은 라운드에서 없앤다.
못 없애면 켜지 않고 남은 위반을 태스크로 넘긴다. 곁가지로 하네스를 빠뜨린 테스트 다섯을 채운다.

- [ ] 켠 규칙마다 일부러 깨뜨린 예가 실제로 잡히는 것을 PR 본문이 보인다
