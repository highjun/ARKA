## 설명

`pnpm run task create`가 찍는 `created:`가 UTC 날짜다. 이 기계는 KST라 09시 이전에 만든 태스크가
전날로 기록된다 — 이 파일 자신이 그렇게 만들어졌다(로컬 2026-09-14, 파일에는 2026-09-13).

커밋·문서의 날짜는 로컬 기준이라 태스크만 하루 어긋난다. 태스크 순서를 날짜로 읽을 때 헷갈린다.

## 인수 조건

- [ ] `ops/tasks/main.ts`가 로컬 날짜로 `created:`를 찍는다
- [ ] 테스트가 타임존을 고정해 경계 시각에서 로컬 날짜가 나오는지 본다
