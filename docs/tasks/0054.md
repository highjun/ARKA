## 설명

[ADR 0008](../adr/0008-component-surface.md)이 정한 것 중 **판단이 필요 없는 것만** 한 라운드로 모은다.
컴포넌트마다 흩어 놓으면 같은 치환을 여덟 번 검토하게 된다.

- `shared/components/{common,layout,markdown}/`을 **`shared/component/`로 평평하게** 옮기고 별칭을 `#component/<Name>`로 둔다. 그룹 배럴 셋과 루트 배럴을 지우고 경로 import로 바꾼다 — 배럴이 없으면 "배럴에서 빠뜨렸다"가 생기지 않는다(넷이 빠져 있었다).
- **아무도 안 쓰는 것 열을 지운다** — `Bold`·`Italic`·`Highlight`·`Code`(원소 하나에 선언 한 줄), `Collapsible`, `Divider`, `Slider`, `ShortcutBar`, `List`, `QuoteBlock`. `@radix-ui/react-slider` 의존성도 함께 나간다.
- **`forwardRef`를 `ref` prop으로 바꾼다**(34파일). 하네스의 `implementsForwardRef`는 보는 것이 그대로이므로 이름만 `implementsRef`로 고친다.
- **자작 셋을 기성품으로 바꾼다** — `useControlledState` → `@radix-ui/react-use-controllable-state`(지금은 전이 의존성이라 직접 의존성으로 올린다), `mergeClassNames` → `clsx`(12곳), `assembleCompound` → `Object.assign`(부품 없는 17곳은 그냥 export).
- **`<Name>RootProps` + 별칭을 `<Name>Props` 하나로** 줄이고, `style`을 `Omit`으로 막던 여덟 곳을 통과시킨다.
