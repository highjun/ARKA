## 설명

층 1(린트·테스트)이 못 잡는 것은 지금 전부 사람에게 온다(→ [ADR 0015](../adr/0015-review-tiers.md)). 구현한 에이전트와 다른 에이전트가 PR을 먼저 보고 세 가지만 판정한다 — 계약(`contracts/`·`I*.ts`) 위반, 태스크 인수 조건 밖의 변경, `docs/adr/` 결정과의 충돌.
지적은 PR 리뷰 코멘트로 남기고, 구현 에이전트가 고치거나 반박한다. 이의가 남아 있으면 자동 머지가 막힌다. 워크플로에서 도는 자리와 프롬프트는 이 태스크에서 정한다. TASK-75~77이 먼저 끝나야 한다 — 크기 상한이 없으면 리뷰 에이전트도 못 읽는다.

## 인수 조건

- [ ] PR을 열면 리뷰 에이전트가 돌고 결과가 PR 리뷰로 남는다
- [ ] 세 관점 밖의 지적(스타일 등)은 내지 않는다 — 프롬프트에 명시
- [ ] 이의가 남은 PR은 자동 머지되지 않는다
- [ ] 같은 지적이 두 번 나오면 린트로 내릴 태스크가 생긴다 — 규약에 한 줄
