## 설명

ADR 0005가 "빨간 검사는 켜지 않는다"고 정했으므로 CI에 VRT 잡이 없다. 지금 빨간 이유는
TASK-35가 적은 그대로다 — FileTree 기준 이미지가 ade9e3a(밀도 토큰) 이후로 낡았다.
순서가 있다: 기준 이미지를 검토해 다시 만들고, 초록을 확인한 뒤에 잡을 켠다.

켤 때 걸리는 것이 둘이다. VRT는 `docker run`으로 playwright 이미지를 띄우므로 러너에
docker가 필요하고(GitHub 러너에는 있다), `updateSnapshots: "none"`이라 **기준이 없는
스토리는 실패가 아니라 건너뜀**이다 — 새 스토리가 조용히 통과하는 것은 그대로 남는다.

CI에서 기준 이미지를 자동 갱신하지 않는다. 갱신은 검토에서 Accept할 때 사람이 한다
(CONVENTIONS.md 테스트 절) — 자동으로 하면 "검토 안 함"이 "승인됨"으로 기록된다.
